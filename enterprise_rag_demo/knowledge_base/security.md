# Northstar Labs — Customer-data security checklist

Fictional demonstration data. Effective 1 November 2026.

## Storage and access
Customer-data tools must keep customer content and backups exclusively in India.
SAML SSO is mandatory for employee access to customer-data systems.
Require role-based access and administrator audit logs.

## Lifecycle
Vendors must offer customer-data deletion within 30 calendar days after contract termination.
Security reviewers must verify the vendor's commitments and record review completion.
Signing a data processing agreement is a separate requirement from security review.

## Evidence gaps
No vendor in this demo has a recorded completed internal security review.
The knowledge base does not contain signed data processing agreements or independently verified certifications.
Do not infer completed approvals from a vendor's feature list.
